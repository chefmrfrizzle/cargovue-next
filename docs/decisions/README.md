# Architecture decision records

ADRs record decisions that are expensive to reverse. Use the next number, copy the template, and keep
the old decision even when superseded.

Filename: `ADR-0007-short-title.md`

## Template

```markdown
# ADR-0007 — Title

Status: proposed | accepted | superseded  
Date: YYYY-MM-DD

## Context

What forces and risks matter?

## Decision

What did we choose?

## Consequences

What becomes easier, harder, required, or forbidden?
```
